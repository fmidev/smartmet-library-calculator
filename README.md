# smartmet-library-calculator

Part of [SmartMet Server](https://github.com/fmidev/smartmet-library-spine). See the [SmartMet Server documentation](https://github.com/fmidev/smartmet-library-spine) for an overview of the ecosystem.

## Overview

The calculator library provides time series and area calculation tools for QueryData, used by SmartMet Server plugins and tools to compute statistical aggregates over time ranges and spatial areas.

## Features

- Time series statistical calculations (mean, min, max, etc.)
- Area-based aggregation over grid regions
- Integration with the QueryData format
